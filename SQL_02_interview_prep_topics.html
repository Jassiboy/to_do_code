SQL problem patterns, topic by topic — from concept to complex

Every SQL interview question is really a variation on a handful of underlying patterns. This bank groups 8 core patterns — the ones beyond plain GROUP BY and islands-and-gaps you already know — into one concept-level warm-up and one deliberately harder, multi-twist version per topic. Each card ships SQL + PySpark, sample data, and a hidden solution.
